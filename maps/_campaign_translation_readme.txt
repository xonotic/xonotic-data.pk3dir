
	How to start translating the campaign

Important: first update Xonotic Git or Autobuild to make sure you have the latest version of the
campaign and a translation to your language doesn't exist yet.

Make a copy of <campaign_filename>.txt.tr._template, replace the _template extension with your
language code, open it in a text editor and start translating it.

Warning: do not delete <campaign_filename>.txt.tr._template
